# Danh sách màn hình cần nghiệm thu

Chỉ đánh dấu hoàn tất sau khi kiểm tra canvas và tương tác. Việc gửi prompt
hoặc màn xuất hiện chưa đồng nghĩa tất cả validation đã đúng.

## Xác thực
- [ ] Đăng nhập + lỗi thông tin
- [ ] Đăng ký tài xế → tự đăng nhập → hồ sơ
- [ ] Đổi mật khẩu + lỗi + thành công giữ phiên
- [ ] 403 + quay lại tổng quan

## Admin
- [ ] Tổng quan: đúng 4 chỉ số, 10 phiên, không hành động phiên
- [ ] Danh sách tài xế: tìm kiếm, lọc hồ sơ, phân trang
- [ ] Chi tiết tài xế: GPLX, mặt, duyệt tổng thể, tài khoản
- [ ] Phương tiện: danh sách + thêm/sửa xe tải/xe khách
- [ ] Phân công: danh sách + thêm/sửa + kết thúc ngay
- [ ] Phiên lái: danh sách chỉ đọc
- [ ] Vi phạm: danh sách + chi tiết + duyệt + xem xét lại
- [ ] Thiết bị: danh sách + thêm/sửa
- [ ] Loại xe: danh sách + thêm/sửa + xóa nhiều có bảo vệ
- [ ] Loại vi phạm: danh sách + thêm/sửa

## Tài xế — desktop và mobile 390px
- [ ] Tổng quan cá nhân
- [ ] Hồ sơ cá nhân
- [ ] Giấy phép lái xe
- [ ] Xe được giao (chỉ đọc)
- [ ] Phiên lái của tôi (chỉ đọc)
- [ ] Vi phạm của tôi + chi tiết (không lịch sử nội bộ)
- [ ] Đổi mật khẩu

- [ ] Menu theo role; không role switcher
- [ ] Link giữa màn đúng người/xe/phiên/vi phạm
- [ ] Loading, empty, no results, inline error, success, confirmation
- [ ] Xung đột version yêu cầu tải lại
